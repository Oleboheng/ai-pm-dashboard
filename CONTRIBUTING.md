# Contributing Guidelines

Welcome to the AI-Assisted Project Management Dashboard project! Please follow these guidelines to ensure secure and smooth collaboration.

## Branching Strategy
We use a feature-branch workflow:
- `main`: Production-ready code. Protected against direct pushes.
- `feature/your-feature-name`: Branch off from `main` for new features or bug fixes.

## Commit Message Convention
Follow conventional commits:
- `feat: [short description]` for new features
- `fix: [short description]` for bug fixes
- `docs: [short description]` for documentation updates
- `chore: [short description]` for maintenance tasks

## Pull Request Process
1. Create a descriptive branch from `main`.
2. Push your changes and open a Pull Request against `main`.
3. Fill out the PR template completely.
4. Request a review from at least one team member. Ensure all status checks and security scans pass before merging.
